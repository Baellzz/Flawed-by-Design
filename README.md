# Flawed by Design

Визуальная новелла на Ren'Py.

## Как запустить проект

1. Установите [Ren'Py 8.5.3+](https://www.renpy.org/latest.html).
2. Скачайте этот репозиторий: `git clone https://github.com/Baellzz/Flawed-by-Design.git`
3. В Ren'Py Launcher нажмите **Preferences** → **Projects Directory** → укажите папку с проектом.
4. Проект появится в списке → нажмите **Launch Project**.

## Структура

- `game/script.rpy` — основной сценарий.
- `game/screens_custom.rpy` — кастомные экраны (меню, галерея).
- `game/options.rpy` — настройки проекта.
- `game/images/` — картинки.
- `game/audio/` — музыка и звуки.

## Как внести изменения

1. `git pull` — подтянуть свежие изменения.
2. Создать ветку: `git checkout -b feature/название`
3. Внести правки, закоммитить: `git commit -m "Что сделал"`
4. Запушить: `git push -u origin feature/название`
5. Создать Pull Request на GitHub.
